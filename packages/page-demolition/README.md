# @wormhole/page-demolition

A harmless interactive visual destruction game for the Wormhole React playground.

- Tap or keyboard-activate individual screen pieces to break them.
- Total Wipe removes all the tiles at once; Restore resets immediately.
- Works on touch, mouse and keyboard, with a reduced-motion fallback.
- Only React component state changes; never deletes files, modifies the browser, or damages the actual site.
- The experiment has crawlable Persian and English entry pages (SEO metadata + sitemap + reciprocal hreflang).
