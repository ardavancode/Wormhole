# @wormhole/mouse-virus

A standalone and entirely fictional cursor-infection experiment.

- Mouse-only runaway buttons and visual fake cursors inside the minigame sandbox.
- Touch and keyboard users can click the fake control buttons directly.
- Fake alerts and a fake infection meter, clearly labeled as simulation.
- Reset/Pause and an explicit way back to the homepage.
- No downloads, permissions, real mouse hijacking, persistence or data collection.
- Persian and English routes, static SEO metadata, reciprocal hreflang and sitemap entries.

This package does not affect any other Wormhole experiment.
