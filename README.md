## SEO and discovery

- Main indexable site: **https://ardavancode.github.io/Wormhole/**
- Persian and English have separate URLs (`/`, `/en/`) with reciprocal hreflang tags.
- The Cloudflare deployment remains an alternate host and declares GitHub Pages as canonical.
- Static titles, descriptions, social metadata, WebSite structured data, a sitemap, and readable homepage content are included.
- Submit `https://ardavancode.github.io/Wormhole/sitemap.xml` to Google Search Console.
- On GitHub Pages, `/Wormhole/robots.txt` is not the domain-root robots file; crawlers will look for `https://ardavancode.github.io/robots.txt` instead.
- Indexing and ranking are controlled by search engines and cannot be guaranteed.
